## Project Overview

Pixel-perfect adaptive landing page for the Louvre museum, built with vanilla
HTML/CSS/JS - no frameworks. Learning project (RS School) focused on
semantic markup, responsive layout and DOM-driven interactivity from scratch

### Specification

- https://github.com/rolling-scopes-school/tasks/blob/master/tasks/museum/museum.md

### Figma design

- https://www.figma.com/design/xkP6mIaq7uG1Uru7CpasXq/Museum-04.09?node-id=0-1&p=f&t=7b0tURqsAFRxVp7R-0

## Features

- Adaptive layout
- Custom slider
- Image comparison slider
- Custom video player with controls
- Ticket booking popup / modal form
- Scroll-triggered animations in the gallery section
